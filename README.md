Coffee Shops Tia Rosa - Sistema de Gestão

Projeto desenvolvido para a verificação de aprendizagem da disciplina de Desenvolvimento de Sistema em Python no Instituto de Educação Superior de Brasília (IESB).

 Sobre o Projeto
O Coffee Shops Tia Rosa é uma cafeteria tradicional que necessitava de digitalização em seus processos internos. Este sistema em Python via linha de comando (CLI) foi desenvolvido para solucionar gargalos operacionais e melhorar a experiência dos clientes e colaboradores.

 Funcionalidades
- Cardápio Organizado: Consulta de produtos categorizados (Bebidas e Comidas) com exibição de ingredientes e preços.
- Programa de Fidelidade: Cadastro de clientes por CPF com acúmulo automatizado de pontos baseados em compras.
- Módulo de Pedidos: Registro rápido de itens com cálculo de subtotal e total dinâmicos.
- Relatório Financeiro: Consolidado de vendas e faturamento diário para controle da gestão.


 Tecnologias Utilizadas
Linguagem: Python 3.x
struturas aplicadas: Dicionários, Listas, Funções, Loops de repetição e Tratamento de Exceções (`try/except`).
